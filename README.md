# 库存记录（stock）

本地离线记账式库存管理 App。Kotlin + Jetpack Compose + Material 3 + Room。

## 设计要点

**只存流水，不存库存。** 库存 = `SUM(Txn.delta)`，入库记正数、出库记负数。
好处是可以追溯每一次变动，撤销就是删掉那条流水，不存在"改错了数字找不回来"。

## 功能

- 主页：搜索框 + 库存列表 + 右下角「记录」按钮。
- 记录：底部弹窗里选入库/出库 → 输入名称（已有物品会显示联想标签，点一下填入）→
  填数量 → 确定。名称不存在时自动新建物品。
- 出库有校验：超过当前库存会被拦下并提示，不会出现莫名负数。
- 点物品卡片 → 看该物品全部流水，每条可以撤销。
- 库存为负数时标红（正常流程下不会出现，除非导入的数据本身为负）。
- 备份：右上角「⋮」→ 备份与恢复 → 导出/导入 CSV。
- Android 12 及以上自动取系统壁纸配色（Material You）。

## 数据

```
Item(id, name 唯一, category, unit)
Txn(id, itemId, delta, note, time)
```

## 构建

推送到 `main` 分支，或在 Actions 页手动点 `Build APK` → `Run workflow`。
构建完成后在本次运行的 Artifacts 里下载 `stock-debug-apk`。

debug APK 用 debug keystore 自动签名，可以直接安装。

> **签名提醒**：以后如果改用正式签名的包覆盖安装，系统会因签名不一致拒绝安装，
> 只能先卸载（数据会丢）。所以正式使用前，先导出 CSV 备份。

## CSV 格式

```
名称,分类,单位,变动,备注,时间
螺丝刀,工具,把,2,,2026-01-01 10:00:00
螺丝刀,工具,把,-1,借给老王,2026-01-02 09:30:00
```

`变动` 正数=入库，负数=出库。导入是**追加**语义：按名称匹配物品，匹配不到就新建。
同一份文件导两次，数量会翻倍。
