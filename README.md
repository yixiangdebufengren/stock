# 库存记录（stock）

本地离线库存管理 App。Kotlin + Jetpack Compose + Material 3 + Room，单人使用，数据全在手机里，不联网。

**下载安装**：到 [Releases](../../releases/latest) 下载 `stock-v*.apk` 直接安装。

---

## 核心设计

**只存流水，不存库存。** 库存 = 该物品所有流水 `delta` 之和，入库记正、出库记负。

好处是每一次变动都能追溯，撤销只是删掉那条流水，不存在"把数字改错了找不回来"的情况。

允许库存变成负数（现实中经常漏记），但界面上会标红提醒。

## 功能

### 主页
- 搜索框：按名称或分类模糊搜索。
- 分类筛选条：自动列出已有分类，再点一次取消筛选；有库存不足的物品时最前面多一个「库存不足 N」筛选。
- 小字提示「共 N 种物品」。
- 点任意物品卡片进入出入库弹窗；卡片上有铅笔图标可直接编辑。

### 点击物品 → 出入库弹窗
- 自动聚焦数量框并弹出数字键盘。
- 「入库 + / 出库 −」切换，实时显示「操作后：xx」。
- 快捷按钮 `+1` `+5` `+10` `+50`，在已填数量上累加。
- 出库超过现有库存时输入框变红并提示"将变为负数"，但不阻止提交。
- 弹窗下方直接列出该物品最近 8 条流水，不用再跳到单独的历史页。

### 批量出入库（全屏页）
- 整批统一方向，搜索过滤，每行 `− / 数量 / +`。
- 填了数量的行整行高亮，并预览「→ 操作后数量」。
- 底部一个备注框整批共用，提交按钮显示「提交 N 项 · 共 M」。
- 整批在一个数据库事务里写入，系统返回键就是关闭本页。

### 新增物品
名称必填，分类可选（点已有分类 Chip 填入），单位默认「个」，初始数量大于 0 时自动生成一条备注为「初始库存」的入库流水。名称重复会红字提示，不会关窗也不会崩溃。

### 编辑 / 删除物品
可改名称、分类、单位、最低库存。改名撞车会提示而不是崩溃。删除需要二次确认，会连同该物品的全部流水一起删掉。

### 低库存提醒
给物品设「最低库存」（0 = 不提醒）。当 `现有 <= 最低库存` 时卡片上出现「库存不足」标签，也能用顶部 Chip 一键筛出所有库存不足的物品。

### 撤销
单个和批量出入库成功后，提示条上都带「撤销」，点一下就把这次写入的流水按 id 删掉。新增物品不提供撤销。

### 导出 CSV
右上角「⋮」→「导出 CSV」，选保存位置即可（默认文件名 `库存导出_yyyyMMdd.csv`）。

- 文件带 BOM，Excel / WPS 打开中文不乱码。
- 内容分两段：先是「库存汇总」（名称、分类、单位、现有数量），空一行，再是「流水明细」（时间、名称、分类、变动、备注）。
- 字段含逗号、引号或换行时按 CSV 规范用双引号包裹。

## 数据与升级

```
Item(id, name 唯一, category, unit, minQty)
Txn(id, itemId, delta, note, time)
```

数据库版本 **2**。从 v1.0（version 1）升级时走 `MIGRATION_1_2`，只做
`ALTER TABLE Item ADD COLUMN minQty INTEGER NOT NULL DEFAULT 0`，
**不会删库重建，旧数据完整保留**。

## 签名与备份（重要）

APK 用 debug keystore 自动签名，可以直接安装、可以覆盖升级。

但如果以后换用正式签名的包，系统会因签名不一致拒绝覆盖安装，只能先卸载——**卸载会丢数据**。所以请养成定期「导出 CSV」的习惯，换机或重装后再想办法导入（导入功能尚未实现）。
